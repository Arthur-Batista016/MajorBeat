# Major Beat — O agente digital do músico
![Logotipo_MajorBeat](/MajorBeat/MajorBeat/Resources/Images/logotipo_image.png)
> Aplicativo móvel desenvolvido para conectar músicos e bandas independentes a contratantes que buscam serviços musicais para festas, eventos e estabelecimentos.

O **Major Beat** é um aplicativo móvel desenvolvido como projeto de conclusão do **Curso Técnico em Desenvolvimento de Sistemas**, com o objetivo de aproximar músicos independentes de pessoas e estabelecimentos que procuram atrações musicais de forma rápida, prática e menos burocrática.

Desenvolvido ao longo do ano letivo de **2025** na **ETEC  Prof. Horácio Augusto da Silveira** como **Trabalho de Conclusão de Curso (TCC)**, o projeto abrangeu todas as etapas essenciais para a concretização da solução, desde a pesquisa inicial, planejamento e prototipagem, até o desenvolvimento, integração e apresentação final.

## 🏦 Sobre a Harmoniar
A **Harmoniar** é uma empresa fictícia criada no contexto deste projeto para representar a organização responsável pelo desenvolvimento e disponibilização do Major Beat.

![Logotipo_Harmoniar](/MajorBeat/MajorBeat/Resources/Images/harmoniar_logotipo.png)

Muitos músicos independentes enfrentam grandes desafios para se estabelecer profissionalmente, especialmente na divulgação de seu trabalho, obtenção de novas oportunidades e construção de uma carreira financeiramente sustentável.

Ao mesmo tempo, pessoas e estabelecimentos que desejam contratar atrações musicais podem encontrar dificuldades para localizar artistas que atendam às suas necessidades.

Diante desse cenário, a Harmoniar propõe uma solução que conecta esses dois públicos por meio de uma plataforma digital.

## 📱 Sobre o Projeto
O **Major Beat** é uma aplicação móvel desenvolvida para conectar **músicos e bandas independentes** com **contratantes** que buscam serviços musicais para animar festas, eventos ou estabelecimentos.

A plataforma busca proporcionar uma experiência simples e acessível para ambos os lados, permitindo que artistas tenham maior visibilidade e novas oportunidades profissionais, enquanto contratantes podem encontrar atrações musicais de maneira mais prática.

O projeto também busca contribuir para a profissionalização do trabalho de músicos autônomos, oferecendo uma alternativa tecnológica para divulgação e contratação de seus serviços.

### Objetivos
O Major Beat foi desenvolvido com os seguintes objetivos:
1. **Fornecer ferramentas de visibilidade** para músicos e bandas independentes;

2. **Transformar talentos em carreiras sustentáveis**, facilitando o acesso a novas oportunidades profissionais;

3. **Inovar no mercado musical**, utilizando tecnologia para aproximar artistas e contratantes;

4. **Apoiar o crescimento contínuo** dos artistas por meio de novas oportunidades e maior alcance profissional.

### Objetivo geral
Desenvolver uma plataforma móvel capaz de conectar músicos e bandas independentes a potenciais contratantes, simplificando o processo de divulgação, busca e contratação de serviços musicais.

## Funcionalidades
Entre as principais funcionalidades planejadas/desenvolvidas para o Major Beat estão:
- Cadastro e gerenciamento de usuários;
- Cadastro e apresentação de músicos e bandas;
- Busca por artistas e serviços musicais;
- Localização e descoberta de artistas;
- Apresentação de informações e características dos músicos;
- Aproximação entre músicos e contratantes;
- Gerenciamento de oportunidades de contratação;
- Avaliação dos serviços prestados;
- Interface desenvolvida para dispositivos móveis.

## ⚙ Pré-requisitos
Para executar o projeto localmente, é necessário possuir as ferramentas e ambientes correspondentes às tecnologias utilizadas.

### Aplicativo
- .NET SDK compatível com a versão utilizada no projeto;
- Visual Studio;
- Componentes necessários para desenvolvimento com .NET MAUI;
- Emulador Android ou dispositivo físico compatível.
### API / Back-end
- Java JDK compatível com a versão utilizada;
- Maven;
- IDE compatível com projetos Java/Spring Boot;
- SQL Server;
- Configuração das credenciais e conexão com o banco de dados.
### Aplicação Web
- Node.js;
- npm;
- Angular CLI.

## Como Executar

### 1. Clone o repositório
>git clone https://github.com/Matheus12Santos/MajorBeat.git<br>
>cd MajorBeat

### 2. Configure o banco de dados
Crie uma instância do SQL Server e configure o banco de dados de acordo com os scripts disponibilizados no projeto.

Configure também as informações de conexão no arquivo de configuração da API.

### 3. Execute a API
Acesse o diretório do back-end:
cd https://github.com/EduardoPQueiroz/API_MAJORBEAT.git

Execute o projeto utilizando a IDE ou os comandos disponibilizados na documentação do projeto.

### 4. Execute a aplicação Web
Instale as dependências:

>npm install

Execute a aplicação:

>ng serve

A aplicação estará disponível no endereço local configurado pelo Angular.

### 5. Execute o aplicativo móvel

Abra o projeto .NET MAUI no Visual Studio, selecione um dispositivo ou emulador compatível e execute a aplicação.

>⚠️ Para uma execução correta, a API e o banco de dados devem estar devidamente configurados e disponíveis.
